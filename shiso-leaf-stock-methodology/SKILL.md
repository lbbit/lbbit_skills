# shiso-leaf-stock-methodology

## 目的

将“紫苏叶理论 / 瓶颈点理论”沉淀为可复用的股票研究方法论，帮助 agent 从用户提供的候选池、产业链材料、公司信息或研究笔记中筛选潜力更大、证据链更完整、风险更可控的标的。

本 skill 关注的是判断逻辑和研究步骤：
- 找高景气产业链中被忽视但不可或缺的瓶颈环节
- 判断公司是否具备稀缺供给、客户认证、工艺壁垒或产能瓶颈
- 用估值位置、业绩拐点、市场拥挤度和风险否决项做二次筛选
- 输出可审计的研究结论，而不是直接喊买入或给收益承诺

## 使用边界

- 只做研究框架、候选排序和风险提示。
- 不承诺收益率、胜率、目标价或买卖点。
- 不提供具体信息获取渠道，例如实时行情、大盘数据、新闻源、研报源、财报下载路径等。
- 若用户没有提供候选池或基础材料，先输出“需要补充的信息字段”，不要编造数据。
- 若资料来自网红、匿名账号、社媒截图或二手摘要，降低置信度，并把“可验证性不足”列为核心风险。

## 核心思想

“金枪鱼大腹”是已经被市场充分关注的主角，例如终端龙头、最显眼平台公司或热门整机厂。“紫苏叶”是看似不起眼但缺了它整条链条就运转不畅的关键配套：材料、零部件、工艺设备、特殊产能、认证供应商、上游稀缺资源或专用软件工具。

优先寻找：
- 大赛道中的小环节，而不是小赛道中的大公司
- 真实物理瓶颈，而不是单纯概念叙事
- 供给受限、替代困难、客户认证周期长的环节
- 市场关注度低但下游需求正在快速扩张的公司
- 估值尚未充分反映业绩拐点的标的

## 分析流程

### 1. 定义超级周期

先确认候选公司依附的下游是否处于长期扩张周期。常见特征包括：
- 需求不是短期主题炒作，而是由技术迭代、资本开支、政策目标或产业升级驱动
- 下游扩张会带来真实出货、产能建设、设备采购或材料消耗
- 需求增长能穿透到上游细分环节，而不是只停留在终端品牌或概念口号

若无法说明“为什么未来 2-5 年需求会持续增长”，先不要进入个股筛选。

### 2. 绘制产业链瓶颈图

把产业链拆成终端、核心系统、关键零部件、关键材料、专用设备、工艺服务、稀缺资源等层级。逐层问：
- 这个环节缺货会不会拖慢整个产业扩张？
- 替代方案是否成熟，切换成本是否低？
- 是否存在物理约束，例如良率、散热、损耗、纯度、精度、稳定性、认证周期、矿产供给或产线爬坡？
- 市场是否更关注下游龙头，而低估了这个上游约束？

优先保留能被“物理限制 + 供需缺口 + 替代困难”共同解释的环节。

### 3. 识别“紫苏叶”公司

候选公司需要尽量满足以下条件：
- **不可或缺**：产品或服务是下游扩张绕不开的刚需，不是可选装饰。
- **不易替代**：存在技术壁垒、工艺 know-how、客户认证、专利、资源禀赋或产能壁垒。
- **供给集中**：稳定供货企业数量少，最好呈现寡头或准寡头格局。
- **小而有弹性**：市值或收入基数相对不大，下游增量足以显著改变业绩弹性。
- **被忽视**：市场讨论度、机构覆盖、估值溢价尚未明显拥挤。
- **能兑现**：订单、客户导入、产能释放、毛利改善或经营现金流能支撑故事落地。

不要因为公司名字、概念标签或社媒热度直接通过筛选。

### 4. 做四道硬过滤

若任一项明显不合格，降级或剔除：

1. **瓶颈硬度**：是否真的卡住产业链，而不是普通供应商。
2. **竞争格局**：是否有太多同质化竞争者，或下游能轻易压价。
3. **估值位置**：是否已经被短期爆炒，估值是否透支 2-3 年乐观预期。
4. **业绩验证**：收入、利润、订单、产能、客户或现金流是否至少有一项出现可验证改善。

## 评分框架

用 100 分制做相对排序。评分不是预测收益，而是衡量研究质量和潜在不对称性。

| 维度 | 权重 | 评分要点 |
|---|---:|---|
| 下游超级周期 | 15 | 需求持续性、扩张空间、资本开支或出货确定性 |
| 瓶颈硬度 | 20 | 物理约束、技术难度、替代成本、缺货影响 |
| 竞争格局 | 15 | 供给集中度、客户认证、议价能力、进入壁垒 |
| 公司弹性 | 15 | 市值/收入基数、增量订单对利润的敏感度 |
| 估值与拥挤度 | 15 | 估值分位、涨幅位置、机构覆盖、交易拥挤度 |
| 业绩兑现 | 15 | 订单、产能、毛利、现金流、客户验证 |
| 风险可控 | 5 | 流动性、治理、单一客户、政策和周期风险 |

分层建议：
- **80-100 分：重点研究**，但仍需等待更多验证和合理价格。
- **65-79 分：观察池**，逻辑有亮点但证据链或估值不够舒服。
- **50-64 分：主题相关**，可能只是产业链普通参与者。
- **低于 50 分：剔除**，瓶颈不硬、太拥挤或兑现难度大。

## 风险否决清单

出现以下情况时，不要给出积极结论：
- 主要依据来自无法验证的收益截图、匿名账号、单篇社媒爆文或二手转述
- 股价已因同一逻辑短期大幅上涨，流动性不足且换手异常
- 公司只是“沾边”概念，主营收入与目标瓶颈关系很弱
- 下游需求真实，但该公司没有明确客户、订单、产能或技术认证证据
- 竞争者很多，产品差异小，下游议价能力强
- 依赖单一客户、单一资源、单一政策补贴或单一项目
- 财务质量差，例如长期亏损、现金流恶化、应收账款异常、频繁融资稀释
- 管理层诚信、治理结构、信息披露存在明显瑕疵

## 输出格式

当用户要求筛选或比较候选股时，按以下结构输出：

```markdown
## 结论分层

| 层级 | 标的 | 一句话理由 | 关键待验证点 |
|---|---|---|---|

## 单标的分析

### [标的名称]
- 紫苏叶定位：它卡住产业链的哪个环节
- 下游超级周期：需求为什么可能持续
- 瓶颈证据：物理限制、技术壁垒、认证壁垒或供给集中度
- 业绩弹性：订单、产能、毛利、收入或利润拐点
- 估值与拥挤度：是否已被充分定价
- 主要风险：至少列出 3 项
- 综合评分：X/100
- 结论：重点研究 / 观察池 / 主题相关 / 剔除

## 需要补充的信息
- [缺失字段 1]
- [缺失字段 2]
```

## 案例抽象模板

不要机械套用具体历史案例，要抽象成可迁移的判断句：

- AI 算力链：不要只看 GPU 或云厂商，继续追问“高速互联、光模块、衬底、散热、电源、先进封装、测试设备中哪个环节最难扩产”。
- 机器人链：不要只看整机和品牌，继续追问“减速器、丝杠、传感器、关节模组、控制器中哪个环节认证慢、良率难、供给少”。
- 新材料链：不要只看材料名称，继续追问“纯度、稳定性、规模化良率、上游资源、环保约束和客户验证是否构成真瓶颈”。
- 国产替代链：不要只看替代空间，继续追问“客户是否愿意切换、切换成本多高、是否已进入关键客户供应链”。

## 反模式

- 把“冷门小盘”直接等同于“紫苏叶”。冷门只是现象，不可替代才是核心。
- 把“涨得快”当成验证。短期暴涨可能意味着不对称机会已经消失。
- 只讲故事不看兑现。真正的紫苏叶应能逐步反映到订单、毛利、产能或现金流。
- 只看公司不看环节。同一家公司的不同业务中，只有真正卡住产业链的业务才值得纳入分析。
- 忽视退出难度。小盘和低流动性标的即使逻辑正确，也可能因为交易结构导致实际风险很高。

## 最终校验

输出结论前，逐项自检：
1. 是否没有提供或暗示实时数据获取渠道？
2. 是否区分了事实、推断和待验证假设？
3. 是否至少列出 3 个主要风险？
4. 是否避免了“必涨、稳赢、确定翻倍”等确定性表述？
